# Rawframe Project

Building blocks for games and real-time simulations: an engine, a scripting language, and a family of standalone C libraries. Kest and the Maul libraries are MIT licensed; Rawframe Engine is source-available under its own license.

| Project | What it is |
|---|---|
| [Rawframe Engine](https://github.com/Rawframe-Project/rawframe-engine) | A network-first 2D and 3D game engine with a C++23 core and a dedicated server that never links rendering code. Source-available. |
| [Kest](https://github.com/Rawframe-Project/kest) | A statically typed language for games and simulations, with a bytecode VM in C and zero dependencies. |
| [Maul2D](https://github.com/Rawframe-Project/maul2d), [Maul3D](https://github.com/Rawframe-Project/maul3d) | Deterministic 2D and 3D physics with bit-exact rollback. |
| [Maul Window](https://github.com/Rawframe-Project/maul-window), [Maul RHI](https://github.com/Rawframe-Project/maul-rhi), [Maul UI](https://github.com/Rawframe-Project/maul-ui), [Maul Audio](https://github.com/Rawframe-Project/maul-audio) | Windows and input, the GPU device layer, user interface, and audio. |
| [Maul Unicode](https://github.com/Rawframe-Project/maul-unicode), [Maul Locale](https://github.com/Rawframe-Project/maul-locale) | Unicode algorithms and locale formatting. |
| [Maul Anim](https://github.com/Rawframe-Project/maul-anim), [Maul Tween](https://github.com/Rawframe-Project/maul-tween), [Maul VFX](https://github.com/Rawframe-Project/maul-vfx), [Maul Nav](https://github.com/Rawframe-Project/maul-nav) | Skeletal animation, tweening, particles and effects, navigation. |

Every Maul library is usable on its own; Rawframe Engine is their first user, not their owner.

These projects are developed with AI coding agents under human direction. How outside contributions work is described in [CONTRIBUTING.md](https://github.com/Rawframe-Project/.github/blob/main/CONTRIBUTING.md) and [AI_POLICY.md](https://github.com/Rawframe-Project/.github/blob/main/AI_POLICY.md).
